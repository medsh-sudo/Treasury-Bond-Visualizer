# ماشین حساب بازده اوراق تامین مالی

یک نرم افزار وب اپلیکیشن پیشرفته برای محاسبه و تحلیل بازده اوراق تامین مالی (اسناد خزانه، مرابحه، صکوک) با استفاده از داده‌های رسمی بازار سرمایه ایران.

## ویژگی‌های اصلی

### 📊 داشبورد تحلیلی
- **آمار کلی**: نمایش تعداد کل اوراق، میانگین بازده، بیشترین و کمترین بازده
- **نمودار توزیع بازده**: نمایش توزیع اوراق بر اساس بازده
- **نمودار نرخ بازده بدون ریسک**: تحلیل روند نرخ بازده بدون ریسک در طول زمان

### 🔍 جدول اوراق تامین مالی
- نمایش کامل اطلاعات اوراق شامل نام، کد، بازده، قیمت، حجم معاملات و تاریخ سررسید
- **وضعیت سررسید**: نمایش وضعیت اوراق (منقضی شده، نزدیک به سررسید، میان‌مدت، بلندمدت)
- **روزهای باقی‌مانده**: محاسبه دقیق روزهای باقی‌مانده تا سررسید
- قابلیت جستجو در اوراق
- مرتب‌سازی بر اساس معیارهای مختلف (بازده، نام، حجم معاملات، زمان تا سررسید)

### 🧮 محاسبه‌گر بازده
- محاسبه دقیق بازده تا سررسید (YTM)
- ورودی‌های قابل تنظیم: قیمت اوراق، ارزش اسمی، نرخ کوپن، زمان تا سررسید
- نمایش نتایج محاسبات با جزئیات کامل

## تکنولوژی‌های استفاده شده

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **نمودارها**: Chart.js
- **فونت**: Vazirmatn (فونت فارسی)
- **API**: استفاده از API رسمی بازار سرمایه ایران

## نحوه استفاده

### اجرای برنامه
1. فایل `index.html` را در مرورگر باز کنید
2. برنامه به صورت خودکار شروع به دریافت داده‌ها از API می‌کند
3. در صورت عدم دسترسی به API، داده‌های نمونه نمایش داده می‌شود

### استفاده از محاسبه‌گر
1. قیمت اوراق را وارد کنید
2. ارزش اسمی اوراق را مشخص کنید
3. نرخ کوپن (درصد) را وارد کنید
4. زمان تا سررسید (سال) را تعیین کنید
5. روی دکمه "محاسبه بازده" کلیک کنید

### فیلتر و مرتب‌سازی
- از فیلد جستجو برای یافتن اوراق خاص استفاده کنید
- از منوی کشویی برای مرتب‌سازی جدول استفاده کنید

## محاسبات مالی

### محاسبه بازده
برنامه از فرمول زیر برای محاسبه بازده استفاده می‌کند:

```
بازده = ((ارزش اسمی - قیمت فعلی) / قیمت فعلی) × 100
```

### محاسبه YTM (بازده تا سررسید)
```
YTM = ((پرداخت کوپن + (تفاوت قیمت / زمان تا سررسید)) / میانگین قیمت) × 100
```
